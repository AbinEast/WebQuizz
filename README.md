# Web Quiz Application - Indonesian General Knowledge

An interactive web-based quiz application built using **HTML, CSS, and JavaScript**. This project aims to test general knowledge regarding Indonesian history and civics with a clean and responsive interface.

## Key Features

* **Auto Timer:** Each question has a **15-second** time limit. If time runs out, the correct answer is automatically revealed.
* **Real-time Scoring:** Automatically calculates correct answers.
* **Instant Validation:** Provides immediate visual feedback (Green for correct, Red for incorrect) when an option is selected.
* **Dynamic Result Messages:** Displays different messages based on the final score (e.g., "Ahai...!", "Waw...", or "Hmmm...").
* **Responsive Design:** The layout adapts to different screen sizes.
* **Question Bank:** Currently includes 10 questions covering Indonesian history and general facts.

## Tech Stack

* **HTML5:** Web content structure.
* **CSS3:** Interface styling (using *Poppins* font & Flexbox).
* **JavaScript (Vanilla):** Quiz logic, DOM manipulation, timer, and scoring calculation.
* **FontAwesome:** Icons for checkmarks and crosses.
